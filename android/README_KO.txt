아마추어무선기사 연습프로그램 · Android 1.0.0
HLØB · 25학번 장영수

설치
- Android 8.0 이상 갤럭시 등 안드로이드용입니다. 아이폰에는 설치할 수 없습니다.
- RadioStudy-Android-1.0.0.apk를 휴대폰에서 열어 설치합니다.
- 직접 배포하는 APK이므로 설치 출처 허용이나 Play Protect 확인이 표시될 수 있습니다.
- 최신 Android System WebView 또는 Chrome을 권장합니다.

기능
- Windows v1.3.2와 동일한 1,834문항/정답/해설. 문제은행과 채점 엔진은 바이트 단위로 대조했습니다.
- 1급: 90문항/90분. 전파법규20, 통신보안10, 전파공학20, 영어20, 무선통신술20.
- 3급 전화급: 50문항/50분. 전파법규20, 통신보안10, 무선설비 취급방법20.
- 모든 과목 40점 이상, 과목별 점수의 산술평균 60점 이상이면 모의고사 합격입니다.
- 3급 통신보안은 기존 프로그램과 동일하게 1급 자료 180문항을 공유합니다.
- 전신급/모스 청음 시험을 재현하지 않습니다. 기존 문제의 신뢰도·법규 시행일 범위도 그대로입니다.
- 앱 자체에 모든 문제를 포함하므로 인터넷 연결 없이 풀이할 수 있습니다. 참고 링크만 외부 브라우저로 엽니다.
- 앱에는 인터넷, 연락처, 사진, 위치, 광고/분석 SDK 권한이 없습니다.

기록
- 답안/오답/북마크와 급수별 최근 모의고사는 각 휴대폰의 앱 내부에 저장됩니다.
- PC와 자동 동기화하지 않습니다. PC의 '기록 내려받기' 파일을 옮겨서 앱의 '기록 가져오기'로 가져올 수 있습니다.
- 가져오기는 현재 앱의 기록을 교체합니다. 먼저 기록을 내려받아 두세요.
- 휴대폰의 '기록 내려받기'를 누르면 원하는 저장 위치에 JSON 파일을 저장할 수 있습니다.
- 앱 삭제/앱 데이터 삭제 시 기록도 삭제됩니다. 기록 JSON을 별도 보관하세요.
- 같은 서명키로 만든 후속 버전을 기존 앱 위에 업데이트 설치하면 내부 기록은 유지됩니다.
- 시험 시간은 앱을 닫거나 화면을 꺼도 계속 흐릅니다. 복귀 시 만료 여부를 확인하여 자동 제출합니다.

검증 범위
- 원본 PC 버전 검사 21개 통과, 문제은행/채점 엔진의 동일성 및 APK 포함 여부 대조.
- 브라우저 UI에서 모의고사 시작/선택/재접속/이어풀기/최종 제출/성적/해설, 연습 채점 확인.
- 360px 화면에서 보기 및 해설을 확인하고 가로 넘침 없음 확인.
- Android SDK 36으로 컴파일, APK v2/v3 서명 검증 및 패키지 구조/CRC 확인.
- 실제 Android 기기나 에뮬레이터에서 설치·실행은 아직 검증하지 못했습니다. 네이티브 파일 가져오기/내보내기, 시스템 뒤로가기 등은 실기기 확인이 필요합니다.

개발/수정
- 질문/보기/정답/해설: app/src/main/assets/questions.json
- 모의고사 과목별 수 및 합격 계산: app/src/main/assets/mock.js
- 휴대폰 스타일: app/src/main/assets/mobile.css
- Android 저장·파일 입출력·외부 링크 처리: app/src/main/java/kr/hl0b/radiostudy/MainActivity.java
- SDK platforms;android-36 / build-tools;36.0.0, Java 17+, Python 3, zip이 필요합니다.
- ANDROID_HOME에 SDK 경로를 지정하고 bash build.sh를 실행하면 output/에 APK가 생성됩니다.
- Linux/WSL 기준 빌드 스크립트입니다. 외부 Java/Android 라이브러리 의존성은 없습니다.
- 앱을 업데이트 배포할 때 AndroidManifest.xml의 versionCode를 반드시 올리고 같은 개인 서명키를 사용하세요.

개발 백업의 private-signing 폴더에는 서명 개인키와 암호가 포함됩니다.
이 백업 ZIP은 제작자 본인만 보관하고 배포하지 마세요.
다른 사람에게는 output/RadioStudy-Android-1.0.0.apk만 배포하세요.
키를 분실하면 같은 앱으로 업데이트 배포하기 어렵고, 키가 유출되면 다른 사람이 같은 서명을 만들 수 있습니다.
