아마추어무선기사 연습프로그램 v1.3.2

실행
1. ZIP을 기존 버전과 다른 새 폴더에 모두 압축 해제합니다.
2. RadioStudy 폴더 안의 RadioStudy.exe를 실행합니다.
3. EXE만 이동하지 마세요. resources·locales·DLL 등 폴더 전체가 필요합니다.
설치 프로그램을 쓰지 않는 압축 해제형 Windows x64 배포본입니다.

첫 화면과 학습 흐름
- 큰 제목: 아마추어무선기사 연습프로그램
- 첫 화면은 모의고사 선택입니다. 1급을 먼저, 3급 전화급을 다음에 표시합니다.
- "전체 문제 풀기"를 선택하면 과목별 연습·오답·북마크·검색 화면으로 이동합니다. 급수 선택도 1급을 먼저 표시합니다.
- "모의고사" 메뉴로 언제든 시험 선택 화면에 돌아올 수 있습니다.

모의고사
- 1급: 90문항 / 90분 / 전파법규 20, 통신보안 10, 전파공학 20, 영어 20, 무선통신술 20.
- 3급 전화급: 50문항 / 50분 / 전파법규 20, 통신보안 10, 무선설비 취급방법 20.
- 과목 면제 없는 전체 시험 기준입니다. 과목당 100점, 모든 과목 40점 이상이고 과목 점수의 산술평균이 60점 이상이면 모의고사 합격입니다.
- 문항 수가 다른 통신보안도 한 과목으로 동일하게 평균에 반영합니다. 전체 정답 수를 전체 문항 수로 나눈 비율로 합격을 판정하지 않습니다.
- 같은 시험 안에서 문제 ID를 중복 출제하지 않습니다. 새 시험을 만들면 과목별로 다시 무작위 추출합니다.
- 최종 제출 전에는 정답·해설을 가리고, 번호로 이동하며 답안을 수정하거나 선택을 지울 수 있습니다.
- 미응답은 오답으로 계산합니다. 제한시간 종료 시 자동 제출합니다.
- 제출 후 과목별 점수·정답·오답·과락과 전체 합격 여부, 개별 문제 해설을 볼 수 있습니다.
- 급수별 최근 시험 1회를 각각 자동 저장합니다. 다른 급수의 시험을 시작해도 기존 급수의 기록은 유지됩니다.
- 시간은 앱을 꺼도 흐릅니다. 다시 켰을 때 이미 시간이 지났다면 자동 제출합니다.
- 이전 v1.2.0의 1급 모의고사 기록도 지원 형식으로 변환해 보존합니다.

한 문제은행과 3급 자료 범위
- 실행 데이터는 source/ui/questions.json 한 파일입니다. 전체 연습과 모의고사가 같은 문제 객체·정답·해설·ID를 사용하며 별도 문제 복사본을 만들지 않습니다.
- 고유 문제는 총 1,834개입니다. 기존 3급 395개 + 1급 추가 자료 1,439개입니다.
- 1급 원자료별 구성: 전파법규 379, 전파공학 360, 통신보안 180, 영어 360, 무선통신술 160.
- 3급 대비 범위: 기존 법규 196 + 무선설비 취급방법 199 + 통신보안 공유 180 = 575문항.
- 3급 통신보안은 현재 3급 원자료가 없어 1급 원자료의 통신보안 문제를 공유합니다. 실제 3급의 난이도·내용 분포와 다를 수 있습니다. 홈·시험 화면과 공유 문항에 해당 사실을 표시합니다.
- 1급과 3급의 학습 범위에는 통신보안 180개가 중복 포함되지만 원본 데이터는 한 번만 저장합니다. 해당 문항을 연습하면 두 급수의 연습 성적에 같은 최근 답안이 반영됩니다.
- 3급 전신급 모의고사는 제공하지 않습니다. 1급 무선통신술도 수록된 문자·부호·해독문 학습 범위이며 음향 청음 시험을 재현하지 않습니다.
- 삭제 표지 1개는 문제에 포함하지 않았습니다.
- 1급 216번은 ② 다중접지, 664번은 ④ C-M형 전력계법으로 사용자 요청에 따라 원자료 답을 채택했으며 독립 검증 완료와 구별해 표시합니다.
- 과거 법규 문제는 지문에 표시한 시행본 기준입니다. 조건 보완·학습용 재구성을 포함합니다.

연습 성적과 개인 기록
- 일반 연습 성적과 모의고사 성적은 별도입니다. 일반 연습은 각 문제의 최근 제출 답안과 푼 문제 기준의 잠정 판정입니다.
- 같은 Windows 계정의 %APPDATA%\RadioStudy\progress.json에 기록을 저장합니다. 백업 파일로 복구하는 기존 방식을 유지합니다.
- 기존 3급 ID 1~395와 내용 개정번호, 추가 1급 ID와 정답·해설을 유지했습니다.
- 오답 복습·북마크, 기록 내려받기·가져오기를 지원합니다. 모의고사 2개 급수의 기록도 내보내기·가져오기에 포함됩니다.
- 다른 PC와 자동 동기화하지 않습니다. 제작자의 개인 풀이 기록은 배포본에 포함하지 않습니다.

문제 추가·수정
- source/ui/questions.json의 id는 중복 없이 유지하고 question·options·answer·explanation을 편집합니다. answer는 1~4, 보기는 4개가 필요합니다.
- 정답 기준이 바뀌면 content_revision을 바꿉니다. 일반 연습의 이전 답안은 보관 후 재풀이하게 하고, 개정된 문제를 포함한 모의고사는 새로 시작하게 합니다.
- 급수는 grade(문자열 1 또는 3), 과목은 subject에 지정합니다. 지원 과목별로 필요한 문항 수가 확보되어야 시험이 생성됩니다.
- 출제 규칙은 source/ui/mock.js의 CONFIGS와 pool()입니다. 3급 통신보안은 현재 grade=1, subject=통신보안을 공유합니다.
- source/content/grade1-reviewed.json은 전체 검토 이력 보관용이며 이 파일만 바꿔서는 실행 데이터에 반영되지 않습니다.
- 수정 후 Windows에서 source/BUILD_WINDOWS.cmd로 다시 빌드합니다. Node.js와 인터넷 연결이 필요합니다.
- 편집한 JSON을 EXE 옆에 두는 것만으로는 반영되지 않습니다.

법령 문항의 설명 보완
- 조문 인용 208문항을 검토해 조항의 주제 설명이 부족한 22문항의 질문을 풀어 썼습니다. 조항 핵심은 문제 풀이 전에는 숨기고 제출 후 해설에서만 표시합니다.
- 원문과 법적 적용 범위는 유지하며, 정답을 그대로 나열하는 요약 대신 조항의 목적·주제도 제출 후 해설에서 안내합니다. 자세한 원칙과 정답 이유는 제출 후 해설에서 확인합니다.
- 일반 연습과 모의고사 모두 제출 후 해설에서만 같은 조항 핵심을 표시합니다.
- 보기·정답·문제 ID·채점 개정번호는 모두 유지해 기존 풀이와 모의고사 기록을 보존합니다.
- 법령문항_보완내역.html과 source/content/law-context-changes.json에서 전체 수정 전·후 내역을 확인할 수 있습니다.

검증
- Node 검사 21개 통과: 전체 문제·기존 정답 보존, 저장·복구·가져오기, 양 급수 출제 과목·문항 수·시험시간, 과락·평균 경계값, 모의고사 기록 분리·이전 버전 변환.
- Chromium UI 검사 통과: 기본 모의고사 화면, 1급 우선 표시, 전체 문제 풀기, 공유 통신보안, 오답·북마크, 두 급수 모의고사·답안 수정·재개, 제출·해설, 미응답·시간 만료, 가져오기·내보내기.
- 1220px/800px 화면 확인. 기존 1,834개 문제의 보기·정답·문제 ID·채점 개정번호를 모두 유지했습니다. 법령 설명 보완 22문항 외의 데이터는 v1.3.0과 동일합니다.
- ASAR의 전체 파일·블록 해시와 EXE 내부 ASAR 헤더 해시, ZIP 무결성을 검사합니다.
- Windows EXE 자체는 이 Linux 제작 환경에서 실제 실행하지 못했습니다. 코드 서명이 없는 개인 배포본입니다.
